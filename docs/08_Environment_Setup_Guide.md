# Environment Setup Guide

## 1. Prerequisites
- Docker + Docker Compose
- Node.js (LTS) + npm/yarn
- Java 17+ (for Certify/Mimoto/Verify backends, if running locally rather than via Docker)
- ngrok (or similar) for mobile-to-local tunneling
- Git

## 2. Repository Layout (suggested)
```
/frontend        → React + TS Playground UI
/backend         → Node.js/Express Playground BFF
/infra           → docker-compose.yml, env templates
/docs            → all specification documents
```

## 3. Option A — Full Local Stack (Docker Compose)

1. Clone required Inji repos (or use them as git submodules / prebuilt images):
   - `inji-certify`
   - `inji-wallet` (mobile) and/or `inji-web`
   - `inji-verify`
2. Copy `.env.example` to `.env` in `/infra` and fill in required secrets (DB credentials, issuer/wallet/verifier base URLs).
3. Run:
   ```bash
   cd infra
   docker compose up -d
   ```
4. Verify health checks:
   ```bash
   curl http://localhost:<certify-port>/actuator/health
   curl http://localhost:<verify-port>/actuator/health
   curl http://localhost:<mimoto-port>/actuator/health
   ```
5. Start the Playground BFF and Frontend:
   ```bash
   cd backend && npm install && npm run dev
   cd frontend && npm install && npm run dev
   ```

## 4. Option B — MOSIP Collab Sandbox (faster path)

1. Request/confirm access to the MOSIP Collab sandbox (Certify, Wallet, Web, Verify, Mimoto, eSignet all hosted).
2. Set BFF environment variables to point to sandbox endpoints instead of local Docker services.
3. Skip local container setup for Inji modules; still run Frontend + BFF locally.
4. Note: sandbox is reference-only — do not assume write access beyond test credential issuance/verification.

## 5. Mobile Wallet Testing
1. Install Inji Wallet mobile app (or run via React Native emulator/simulator).
2. Start ngrok tunnels for local BFF/Certify/Verify endpoints:
   ```bash
   ngrok http <bff-port>
   ```
3. Update QR/deep-link generation in the BFF to use the public ngrok URL instead of `localhost`.

## 6. Common Environment Variables (Playground BFF `.env`)
```
CERTIFY_BASE_URL=http://localhost:8090
VERIFY_BASE_URL=http://localhost:8091
MIMOTO_BASE_URL=http://localhost:8092
DB_CONNECTION_STRING=postgres://user:pass@localhost:5432/playground
REDIS_URL=redis://localhost:6379
PUBLIC_BASE_URL=https://<ngrok-subdomain>.ngrok.io
```

## 7. Health-Check Checklist
- [ ] Certify reachable and returns credential offers.
- [ ] Mimoto/Wallet/Web reachable and can request tokens.
- [ ] Verify reachable and returns verification results.
- [ ] BFF can reach all three and normalize responses.
- [ ] Frontend can reach BFF and render the selector UI.
- [ ] QR codes generated by BFF are scannable by the mobile wallet (test with ngrok URL, not localhost).

## 8. Troubleshooting Notes
- **QR not scannable:** check that URLs embedded in the QR use the public (ngrok) host, not `localhost`.
- **Token exchange fails:** check clock skew between containers (JWT `exp`/`iat` validation is time-sensitive).
- **CORS errors in Frontend:** ensure BFF sets appropriate CORS headers for the Frontend's dev origin.
- **Docker Compose network issues:** ensure all services share the same Docker network and use service names (not `localhost`) for inter-container calls.
